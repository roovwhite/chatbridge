# chatbridge

Простой веб-интерфейс для отправки и получения текстовых сообщений в WhatsApp через [GREEN-API](https://green-api.com/).
Тестовое задание на позицию «Фронтенд разработчик React» (вариант для WhatsApp).

- Демо: https://chatbridge-eta.vercel.app
- Репозиторий: https://github.com/roovwhite/chatbridge

## Возможности

- Вход по данным инстанса GREEN-API (`idInstance`, `apiTokenInstance`) с проверкой через `getStateInstance`
- Создание чата по номеру телефона получателя
- Отправка текстовых сообщений (`sendMessage`)
- Получение ответов (`receiveNotification` + `deleteNotification`, HTTP API)
- Статусы сообщений (отправляется, отправлено, ошибка) и повторная отправка
- Счётчик непрочитанных, история чатов сохраняется в браузере
- Адаптивная вёрстка: на узких экранах список чатов и переписка показываются по очереди

## Стек

React 19, TypeScript, Vite, Zustand (состояние и сохранение в `localStorage`), CSS Modules, ESLint. Бэкенда нет: браузер обращается напрямую к GREEN-API.

## Подготовка инстанса GREEN-API

1. Зарегистрируйтесь в [личном кабинете](https://console.green-api.com) и создайте инстанс WhatsApp.
2. Авторизуйте инстанс: отсканируйте QR-код в приложении WhatsApp на телефоне (Связанные устройства, Привязка устройства). Статус инстанса должен стать `authorized`.
3. В настройках инстанса:
   - оставьте поле `webhookUrl` пустым (иначе `receiveNotification` вернёт ошибку);
   - включите уведомления `incomingWebhook`, `outgoingWebhook`, `stateWebhook`.
4. Из консоли возьмите `apiUrl`, `idInstance` и `apiTokenInstance`.

## Локальный запуск

Нужен Node.js 20+ (проверялось на Node 24).

```bash
git clone https://github.com/roovwhite/chatbridge.git
cd chatbridge
npm install
npm run dev
```

Приложение откроется на http://localhost:5173.

Другие команды:

```bash
npm run build     # проверка типов и production-сборка в dist/
npm run preview   # локальный просмотр собранной версии
npm run lint      # ESLint
```

## Как пользоваться

1. Введите `idInstance`, `apiTokenInstance` и `apiUrl` (по умолчанию `https://api.green-api.com`, у вашего инстанса адрес может отличаться, он указан в консоли) и нажмите «Войти».
2. Нажмите «+», введите номер получателя в международном формате (например, `79991234567`) и нажмите «Создать чат».
3. Напишите сообщение и отправьте его (Enter отправляет, Shift+Enter переносит строку).
4. Когда получатель ответит в WhatsApp, ответ появится в чате.

## Заметки по реализации

- **Получение сообщений** это long-polling в цикле: получить уведомление, сохранить в store, удалить из очереди. Удаление идёт после сохранения, поэтому при сбое сообщение может прийти повторно, а дубли отсекаются по `idMessage`.
- **Ошибки**: временные (сеть, таймаут, 429, 5xx) повторяются с нарастающей задержкой; постоянные (неверные данные, исчерпана квота) останавливают получение и показываются баннером.
- **Несколько вкладок**: опрашивает очередь только одна вкладка (Web Locks API), остальные подхватывают данные через `localStorage`. Иначе вкладки разбирали бы очередь между собой.
- **Идентификаторы чатов**: номер превращается в `chatId` вида `79991234567@c.us`, тот же формат приходит во входящих, поэтому ответ попадает в тот же чат. Имя контакта подставляется, когда оно становится известно из входящего сообщения.
- **Типы текста**: обрабатываются `textMessage` и `extendedTextMessage` (текст со ссылкой или ответом); остальные типы уведомлений удаляются из очереди без показа.
- **Отправка** не повторяется автоматически: запрос мог дойти до сервера, и повтор создал бы дубль. Повтор делается кнопкой.

## Ограничения

- `apiTokenInstance` хранится в `localStorage` браузера. Для тестового задания это допустимо, для продакшена токен должен жить на бэкенде.
- Только текстовые сообщения, без вложений, групповых чатов и истории до входа в приложение (GREEN-API отдаёт только новые уведомления, очередь хранится 24 часа).
- Статусы доставки и прочтения не отображаются, только «отправлено».
